# Contributing to FastDPS

Thank you for helping make public procurement software more open and portable.

1. Create a focused branch and keep fixtures synthetic.
2. Add an additive migration for every persistent schema change.
3. Put policy and state transitions in services, not route handlers.
4. Add tests for permissions, tenant isolation, audit history, and both valid
   and invalid transitions.
5. Run the repository verification commands in `AGENTS.md`.

Security issues should not be opened as public issues. Contact the repository
maintainers privately with a reproduction and impact assessment.
